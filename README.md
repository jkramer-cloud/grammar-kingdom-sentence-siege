# Grammar Kingdom: Sentence Siege v2.3.1

Full replacement of Grammar Kingdom v2.3. Includes all 50 campaign levels, five worlds, Survival Mode, achievements, and the existing graphics assets.

## New in 2.3.1
- World selector uses a proper viewport-sized dialog. Ten missions fit without the overlapping labels shown in the earlier version.
- A compact keyboard shortcut guide appears above and below the battlefield on desktop screens; it is hidden when space is too limited.
- The Royal Spell now displays three live charges within the existing illustrated Grammar Power plaque. The glowing book and gold-trimmed frame remain visible, without an extra opaque panel over the art.

## Install
Upload `index.html` and the contents of `assets/` at your existing GitHub Pages repository's root. Retain the same repo URL for browser saves to carry over.

## Controls
1–4: select defender; click/tap: place or inspect; G: grammar challenge; I: inspect; Space: cast at 3/3 charges; P or Esc: pause; A–D: answer questions.

Progress persists locally per site/browser. The question bank is ungraded practice pending teacher review.
