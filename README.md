# Grammar Kingdom: Sentence Siege

**Student playtest release — World 1, v1.7.1**

A colorful, 16-bit-inspired educational tower-defense game for middle-school students. Defend the Royal Courtyard with Quill Archers, Shield Squires, Ink Scribes, and Comma Catapults while practicing English language arts skills through optional grammar challenges.

## What students can play

- **10 Royal Courtyard levels**, ending with the three-phase Baron Blunder boss battle.
- Four defenders, Veteran upgrades, tactical retreat, and a special reinforcement level.
- Grades **5–8** and a **Foundations** practice setting.
- Grammar practice covering identifying language features, punctuation, sentence correction, and application.
- A randomized question rotation intended to reduce repeated prompts and predictable answer positions.

**Status:** This release is for classroom usability and engagement feedback. Grammar questions are draft instructional content and should receive ELA teacher review before the game is used for grades or formal assessment. Four additional worlds are planned, but not included.

## How to play

1. Open the published GitHub Pages link, or open `index.html` locally in a current Chrome or Edge browser.
2. Select the practice level and a Royal Courtyard battle.
3. Place defenders on grassy lanes to protect the castle. Ink accumulates automatically.
4. Use **Grammar Challenge** for additional resources and Grammar Power.
5. Win a battle to unlock the next level.

### Keyboard controls

| Key | Action |
|---|---|
| `1`–`4` | Select defender |
| `G` | Open Grammar Challenge |
| `A`–`D` | Choose question answer |
| `I` | Inspect defender |
| `Space` | Royal Quill Storm |
| `P` | Pause |

## Host using GitHub Pages

The site is static: it needs no build step, server, or paid services.

1. Upload **`index.html` and the entire `assets/` folder** to the repository root (do not upload the ZIP alone).
2. In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
3. Use the published GitHub Pages URL for student access and as a link on the Naches Learning Hub.

The separate teacher-review CSV lists questions for educator review; it is intentionally excluded from this public student-facing repository package.

## Student playtest suggestions

Start by observing how students handle the tutorial and first battles. Useful quick feedback:

- What part made you want to keep playing?
- Where did you get stuck or confused?
- Did grammar questions feel too easy, too hard, or about right?

## Progress and privacy

Progress and recently seen questions are stored locally in each browser. Progress does **not** automatically follow a student between devices, browser profiles, or site addresses. The game does not require student accounts or upload student responses; do not use this local progress as an official grading record.
